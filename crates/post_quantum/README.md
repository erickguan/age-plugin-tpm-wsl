# age-tpm-wsl-post-quantum

This staged module contains the accepted MLKEM768-P256 construction, canonical hybrid identity and bounded TPM custody record. It performs public wrapping and authenticated opening with an opaque agreement callback, without filesystem access or key enrollment. Windows custody must validate the actual PCP identity and restore the ML-KEM key before calling the receiver.

The staged module passes relocated-source validation and independent review, with both advisory conditions closed at commit `e86c9779`. It is now a workspace member with consumer validation and review accepted (`notes/pq-workspace-integration.md`). See the staging acceptance (`notes/pq-module-integration.md`), integration plan (`.agents/pq-integration.md`, local context) and wire/lifecycle contract (`docs/post-quantum-format.md`). The original construction acceptance (`notes/aws-lc-hybrid-evaluation/acceptance.md`), codec (`notes/pq-custody-binding/README.md`) and native disk lifecycle (`notes/pq-custody-binding/final-disk-review-disposition.md`) retain their original source hashes and limits.

The source now lives in `crates/post_quantum`; Rust imports use `age_tpm_wsl_post_quantum`. The package was previously named `age-tpm-wsl-pq`. Historical acceptance reports retain that name and their original source hashes. [source-origin.json](source-origin.json) records the original source relocation. The source-renaming record (`notes/post-quantum-source-renaming.json`) links those staged hashes to the current paths and identifier spelling. Historical staging validators remain tied to their recorded checkout and hashes. Differences are module/import/test-fixture paths and the receiver feature name. The implementation keeps the same combiner, HPKE schedule, canonical encodings and parser checks. The direct vectors and independent Go transcript fixtures remain under `notes/`; tests refer to those original public fixtures.

`seed-restoration` enables the exact reviewed local AWS-LC seed interface. The default public-only build does not enable it. The root workspace patch selects the reviewed source; only the Windows helper dependency requests seed restoration. [Dependency provenance](../../vendor/README.md) identifies the patched safe crate and unchanged native backend. No FIPS approval or comprehensive-erasure claim follows from this module.
